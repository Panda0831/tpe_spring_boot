Tarifs & Moteur d'Attribution

Configuration Globale
Formule de Facturation

Le tarif de chaque course est calculé de manière automatique selon la règle :

Tarif = Tarif_Base + (Prix_Km × Distance_Km)
Commission = Tarif × (Commission_% / 100)
Part_Chauffeur = Tarif - Commission
  • Tarif de base : 2.50 Ar
  • Prix par kilomètre : 1.80 Ar/km
  • Commission société : 20.0 %
Algorithme d'Attribution Automatique

Le dispatcher affecte automatiquement les courses aux chauffeurs éligibles selon un score composite :

Score = (Poids_Proximité × Score_Proximité) + (Poids_Équité × Score_Équité)

• Proximité : calculée par distance entre le point de départ et la dernière position connue du chauffeur.
• Équité : favorise les chauffeurs ayant reçu le moins de courses sur les 30 derniers jours.
• Départage : ancienneté d'embauche en cas d'égalité stricte.
